# Engenharia de Dados

## Responsável
Ricardo da Silva Lacerda

## Objetivo
Processar os logs do projeto de Big Data & Cibersegurança e entregar uma base consolidada para o Analista de BI.

## Atividades realizadas
- Leitura de 178 arquivos CSV.
- Consolidação dos dados em um único DataFrame.
- Verificação da quantidade de linhas e colunas.
- Identificação de valores nulos.
- Identificação e remoção de 8.020 registros duplicados.
- Verificação dos tipos de dados.
- Geração da base tratada.
